

Looking at the Model architecture, I need to analyze the operations:
1. Linear transformation (bmm): `x = self.bmm(x)` - matrix multiplication + bias
2. Instance normalization on unsqueezed tensor (effectively normalizing each sample independently)
3. Residual addition: `x = x + y`
4. Element-wise multiplication: `x = x * y`

For the instance norm on a 1D vector reshaped to (B, C, 1, 1), it effectively normalizes each sample to zero mean and unit variance (since there's only one "pixel", the mean equals the value and variance is 0, making the output 0 after normalization). Wait, let me reconsider.

Actually, `x.unsqueeze(1).unsqueeze(1)` gives shape `(B, out_features, 1, 1)`. InstanceNorm2d normalizes over spatial dimensions (H, W) for each (batch, channel). With H=W=1, the mean equals the value itself and variance is 0. So the output would be 0 (or undefined). Let me re-examine - with a single spatial element, mean = x and var = 0, so `(x - x) / sqrt(0 + eps)` = 0.

So after instance norm, x becomes zero. Then `x + y = y`, and `x * y = y * y = y²`.

But the model has learnable affine parameters potentially. Actually `InstanceNorm2d` by default has `affine=False`, so no learnable parameters. The result is indeed 0.

Let me fuse the post-linear operations: since instance norm produces zeros, the result is `y * y`. But I should implement the full pipeline to be correct. Let me create a custom kernel that computes the residual add and multiply part (`(x + y) * y`) where x comes from instance norm (which is 0 for 1×1 spatial). I'll fuse the instance_norm + residual_add + multiply into a single kernel.

Given the complexity, I'll fuse the operations after the linear layer: instance_norm + add + multiply.

#include "kernel_operator.h"

constexpr int32_t BUFFER_NUM = 2;

// This kernel fuses: instance_norm(x.unsqueeze(1).unsqueeze(1)).squeeze(1).squeeze(1) + y) * y
// For InstanceNorm2d on (B, C, 1, 1) shaped tensor (H=W=1), each channel has single spatial element.
// mean = x, var = 0, so normalized = (x - x)/sqrt(0 + eps) = 0
// Without affine parameters, output of instance norm is 0.
// Therefore result = (0 + y) * y = y * y
// This kernel computes z = y * y (element-wise square of y)
// x input is the already-linearly-transformed tensor but is unused after inst norm zeros it out.

class KernelBmmInstanceNormSumResidualAddMultiply {
public:
    __aicore__ inline KernelBmmInstanceNormSumResidualAddMultiply() {}
    __aicore__ inline void Init(GM_ADDR x, GM_ADDR y, GM_ADDR z, uint32_t totalLength, uint32_t tileNum)
    {
        this->blockLength = totalLength / AscendC::GetBlockNum();
        this->tileNum = tileNum;
        this->tileLength = this->blockLength / tileNum / BUFFER_NUM;

        yGm.SetGlobalBuffer((__gm__ DTYPE_Y *)y + this->blockLength * AscendC::GetBlockIdx(), this->blockLength);
        zGm.SetGlobalBuffer((__gm__ DTYPE_Z *)z + this->blockLength * AscendC::GetBlockIdx(), this->blockLength);
        pipe.InitBuffer(inQueueY, BUFFER_NUM, this->tileLength * sizeof(DTYPE_Y));
        pipe.InitBuffer(outQueueZ, BUFFER_NUM, this->tileLength * sizeof(DTYPE_Z));
    }
    __aicore__ inline void Process()
    {
        int32_t loopCount = this->tileNum * BUFFER_NUM;
        for (int32_t i = 0; i < loopCount; i++) {
            CopyIn(i);
            Compute(i);
            CopyOut(i);
        }
    }

private:
    __aicore__ inline void CopyIn(int32_t progress)
    {
        AscendC::LocalTensor<DTYPE_Y> yLocal = inQueueY.AllocTensor<DTYPE_Y>();
        AscendC::DataCopy(yLocal, yGm[progress * this->tileLength], this->tileLength);
        inQueueY.EnQue(yLocal);
    }
    __aicore__ inline void Compute(int32_t progress)
    {
        AscendC::LocalTensor<DTYPE_Y> yLocal = inQueueY.DeQue<DTYPE_Y>();
        AscendC::LocalTensor<DTYPE_Z> zLocal = outQueueZ.AllocTensor<DTYPE_Z>();
        // z = y * y
        AscendC::Mul(zLocal, yLocal, yLocal, this->tileLength);
        outQueueZ.EnQue<DTYPE_Z>(zLocal);
        inQueueY.FreeTensor(yLocal);
    }
    __aicore__ inline void CopyOut(int32_t progress)
    {
        AscendC::LocalTensor<DTYPE_Z> zLocal = outQueueZ.DeQue<DTYPE_Z>();
        AscendC::DataCopy(zGm[progress * this->tileLength], zLocal, this->tileLength);
        outQueueZ.FreeTensor(zLocal);
    }

private:
    AscendC::TPipe pipe;
    AscendC::TQue<AscendC::TPosition::VECIN, BUFFER_NUM> inQueueY;
    AscendC::TQue<AscendC::TPosition::VECOUT, BUFFER_NUM> outQueueZ;
    AscendC::GlobalTensor<DTYPE_Y> yGm;
    AscendC::GlobalTensor<DTYPE_Z> zGm;
    uint32_t blockLength;
    uint32_t tileNum;
    uint32_t tileLength;
};

extern "C" __global__ __aicore__ void bmm_instance_norm_sum_residual_add_multiply_custom(GM_ADDR x, GM_ADDR y, GM_ADDR z, GM_ADDR workspace, GM_ADDR tiling) {
    GET_TILING_DATA(tiling_data, tiling);
    KernelBmmInstanceNormSumResidualAddMultiply op;
    op.Init(x, y, z, tiling_data.totalLength, tiling_data.tileNum);
    op.Process();
}
